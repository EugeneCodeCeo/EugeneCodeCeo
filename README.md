# EugeneCodeCeo

Начинающий разработчик: AI-assisted разработка и автоматизация. Основная практика — Telegram-сценарии и интеграция сервисов.

Проектирую пользовательские маршруты, формулирую требования, работаю с ChatGPT и OpenAI Codex над реализацией, вручную проверяю поведение и настраиваю развёртывание. Этот опыт не приравниваю к самостоятельному написанию всего кода без AI.

## Технические кейсы

**[Learn and Earn — Telegram-платформы и CRM](https://github.com/EugeneCodeCeo/learn-and-earn-case-studies)**

- **Free:** диагностические маршруты, PDF-уроки, ответы, прогресс и доступ по кодам.
- **Paid:** последовательное обучение, многофайловые домашние задания, статусы проверки и связь с куратором.
- **CRM:** Web-панель, Entry Bot и Manager Bot; заявки, источники, назначения и роли. CRM объединяет собственные интерфейсы; автоматическая синхронизация с Free/Paid не подтверждена.

Стек документированных проектов: **Python, aiogram 3, Telegram Bot API, SQLite** — образовательные боты; **React, FastAPI, PostgreSQL, Docker Compose** — CRM. В кейсах описаны архитектура, ручные проверки и историческое развёртывание на Ubuntu VPS.

Проекты архивные: серверы удалены, последние полные исходники не получены. Репозиторий содержит описание, схемы и обезличенные экраны; текущая работоспособность не заявляется. AI использовался при разработке; LLM внутри ботов не подтверждена.
