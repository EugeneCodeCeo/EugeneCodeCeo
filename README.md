# EugeneCodeCeo

**AI-assisted Development · Telegram Bots · Automation · Integrations**

Занимаюсь разработкой приложений и автоматизацией с использованием ChatGPT и OpenAI Codex. Проектирую пользовательские сценарии, определяю архитектуру решений, участвую в реализации, тестирую функциональность и настраиваю развёртывание.

Основной практический опыт — образовательные Telegram-платформы, backend-интеграции и внутренняя CRM-система.

## Технические проекты

### [Learn and Earn — Telegram-платформы и CRM](https://github.com/EugeneCodeCeo/learn-and-earn-case-studies)

Комплекс из трёх реализованных решений:

- **Free Bot:** диагностические маршруты, PDF-уроки, интерактивные вопросы, сохранение ответов, система прогресса и административное управление.
- **Paid Bot:** образовательная платформа с восемью модулями, практическими заданиями, проверкой работ, системой кураторов и отслеживанием прогресса.
- **CRM:** система управления отделом продаж с React-интерфейсом, FastAPI backend, PostgreSQL и двумя Telegram-ботами для регистрации и обработки заявок.

**Технологии, использованные в проектах:**

`Python` · `aiogram 3` · `Telegram Bot API` · `FastAPI` · `React` · `SQLite` · `PostgreSQL` · `Docker Compose` · `Ubuntu`

Проекты разрабатывались с использованием AI-инструментов. Мой вклад включал проектирование логики, постановку технических задач, тестирование, интеграцию компонентов и развёртывание.

*Проекты архивные: доступны техническая документация, архитектурные схемы и обезличенные скриншоты. Исходники последних версий и действующие серверы недоступны.*
